# QA Assistant Practice

Проект теперь автоматически использует GPU при наличии. Это позволяет значительно ускорить генерацию и расчёт эмбеддингов.

## Ускорение обработки запросов

- Запускайте модель на GPU (`torch.cuda.is_available()`), иначе будет использован CPU.
- Для генерации и эмбеддингов применяется половинная точность (`torch.float16`) на GPU.
- Включайте `torch.backends.cudnn.benchmark = True` для оптимального выбора ядер.
- Можно попробовать квантование через `bitsandbytes` или специализированные движки инференса (например, vLLM, TensorRT) для дополнительного ускорения.
